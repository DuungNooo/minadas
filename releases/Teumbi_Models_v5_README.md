# 틈비 V5 — 승인된 기본형 보존, 속성별 수정

사용자가 마음에 든다고 한 기본형(대화상 ‘톨비’, 파일 ID teumbi)은 V4 그대로입니다. 모델·geometry·텍스처·발광 마스크·모션·소스·GLB·기본형 미리보기 8개 파일의 바이트 일치를 확인했습니다. 기준 해시는 APPROVED_BASE_SHA256.json에 있습니다.

## 수정 내용

- **불꽃:** 두꺼운 판 모양 손을 뾰족한 초승달 날로 바꿨습니다. 날 본체는 양면 알파 면, 실제 절삭면 두께는 0.06~0.30 모델 단위입니다. 0.90 두께의 손목 연결부를 통해 팔 자체가 날로 이어집니다. 날 윤곽과 물리 절삭면이 맞도록 UV 방향도 확인했습니다.
- **물:** 마스카나의 동물형 가면과 이어롭의 굽은 긴 귀·힘 있는 다리 비례를 참고한 원본 물 토끼 계열입니다. 목을 짧게 하고 몸통을 연결했으며, 주둥이·코·마스크·입체 귀·발목 장식·물갈퀴 발을 넣었습니다. 귀의 지연 움직임, 도약 보행, 앞발의 하프 연주를 제공합니다.
- **전기:** 공격을 축전 → 조준 정지 → 정면 방출 → 충격 유지 → 손목·피뢰침 반동 → 복귀로 다시 짰습니다. 손목 본을 추가해 실제 손바닥이 몸 앞의 목표를 향하게 했습니다. 기본 공격은 2단계 0.88초, 최종형 1.40초이며, 특수기는 양손으로 모았다 방출하는 별도 동작입니다.
- **풀/방패:** 고릴타의 큰 상체와 긴 팔, 낮게 버티는 자세를 참고한 원본 숲 유인원입니다. 짧은 목과 다리, 연결된 통 모양 몸통, 땅 가까이 내려오는 큰 앞팔과 잎 갈기를 갖습니다. 고유기는 서로 다른 두 박자의 예비 동작 → 몸 낮추기 → 방패 격돌 → 충격을 받아 버티기 → 무게를 실어 펼치기입니다. 일반 공격은 양팔을 들어 지면을 강타합니다.

## 편집과 적용

blockbench/*.bbmodel은 텍스처와 6개 모션을 내장한 편집 원본입니다. models/*.geo.json, textures/*.png, animations/*.animation.json은 별도 내보내기 파일입니다. GLB는 알파 컷아웃·양면 재질을 포함한 정적 검사 파일이며, 애니메이션은 bbmodel/animation.json을 사용하세요. source는 좌표·본·UV·모션 데이터, tools는 생성·검증·캡처 코드입니다.

모든 모델에 대기·이동·공격·고유기·피격·쓰러짐 모션이 있습니다. 기절은 마지막 자세를 유지합니다. 모션 비교 도구의 --compare-electric 재생성에는 V4 폴더가 V5와 나란히 필요합니다.

## 확인한 범위

- 기본형 파일 8개의 원본 바이트 일치
- 9종 geometry·UV·이진 알파·본 계층과 54개 모션 참조
- 실제 도끼 절삭면의 두께와 뾰족한 알파 윤곽
- 전기 방출 시 손의 전방 위치·손바닥 방향·마지막 복귀 자세
- 물의 연주 앞발과 실제 현 위치의 일치
- 풀의 실제 양쪽 방패 안쪽 면이 뼈대 변환 후 맞닿는지 확인
- Chromium에서 알파·재생·시간 이동·화면 범위 검사

게임 이벤트 연결과 Minecraft/Cobblemon 안에서의 실행은 아직 검증하지 않았습니다. 사용하는 버전에 맞는 종·진화·스폰 및 resolver/poser, 전투 동작 연결이 별도로 필요합니다.

도구는 Python 3/Pillow, 브라우저 캡처는 Node.js/Playwright/Chromium, 정적 GLB 내보내기는 Blender 4.3 이상을 사용합니다. python tools/build.py는 tools/pack에 모델을 재생성합니다. 구조 검사는 python tools/validate.py <pack 경로>, 이번 수정의 기능 검사는 python tools/check_revision.py <pack 경로>입니다. 후자는 승인 기본형·GLB·미리보기가 포함된 완성 패키지를 대상으로 합니다.
