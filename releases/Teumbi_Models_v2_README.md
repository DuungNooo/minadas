# 틈비 — 분기 진화 모델 V2

기존 V1의 큐브 덩어리 형태를 대체하는 새 모델 9종입니다. 1단계는 인간형이 아닌 떠 있는 돌껍질과 단일 코어, 2단계부터 속성별 인간형, 3단계는 전투 역할이 드러나는 서로 다른 체형으로 제작했습니다.

## 먼저 보기

1. `VIEW_MODELS.html`을 브라우저에서 열면 설치나 인터넷 연결 없이 모델을 돌려 볼 수 있습니다. 마우스로 회전하고 휠로 확대합니다. WebGL을 지원하는 데스크톱 브라우저가 필요합니다.
2. `previews`에는 실제 파일의 큐브와 텍스처로 렌더링한 이미지가 있습니다. 생성형 콘셉트 이미지를 미리보기로 사용하지 않았습니다.
3. `blockbench`의 `.bbmodel`을 Blockbench의 **File → Open Model**로 열면 파츠, 본, UV, 텍스처를 편집할 수 있습니다. 텍스처와 세 가지 기본 애니메이션을 파일 안에도 넣었습니다. **Animate** 탭에서 선택해 재생합니다.

## 구성

| 파일 | 용도 |
|---|---|
| `blockbench/*.bbmodel` | 편집용 원본. 텍스처 및 애니메이션 포함 |
| `models/*.geo.json` | Bedrock 1.12 geometry 내보내기 |
| `textures/*.png` | 파츠별 UV를 배치한 불투명 픽셀 텍스처 |
| `textures/*_emissive.png` | 코어·눈·고열부용 발광 마스크. 렌더러의 발광 지원 필요 |
| `animations/*.animation.json` | 별도 런타임 애니메이션 내보내기 |
| `glb/*.glb` | 일반 3D 뷰어용 정적 모델. 애니메이션은 bbmodel/animation.json 사용 |
| `source/*.json` | 검토와 재생성을 위한 큐브·본·UV 데이터 |
| `tools/*.py` | 모델·텍스처·뷰어·미리보기 생성 및 검증 도구 |

텍스처는 파츠 크기에 따라 256 또는 512 픽셀 아틀라스를 사용합니다. 모든 요소는 큐브와 피벗 회전으로 구성했습니다. 기본 대기/걷기와 역할별 공격·방어·연주 포즈가 있으며, 최종 게임용 전투 모션으로 다듬을 수 있도록 본을 분리했습니다.

## 형태

- **틈비**: 비대칭 깨진 돌껍질 안의 노출된 단일 코어. 상단 껍질의 눈과 작은 부유 파편.
- **불꽃**: 현무암 외장과 주황색 균열. 최종형은 넓은 견갑과 팔 자체인 대형 도끼날.
- **전기**: 아이보리 외장, 도체와 황금색 코어. 몸에 고정한 피뢰침, 길게 갈라진 코트형 외장.
- **풀**: 나무·이끼·돌의 수호자. 어린 개체는 분리 방패, 최종형은 중앙에서 맞물리는 두 방패와 나무 문양.
- **물**: 진주색 외장과 청색 물줄기. 몸에 연결된 현악 하프, 분리된 의복형 파츠와 물의 망토.

## 검증 범위

9종의 JSON/PNG, 원본과 내보낸 큐브 수·좌표·피벗·회전, 본 계층, 서로 겹치지 않는 면 UV, 내장/외부 텍스처 일치, 애니메이션 본과 키프레임을 자동 검사했습니다. Blockbench의 공식 Bedrock 코덱과 좌표 변환을 대조했습니다. 실제 geometry를 Blender로 렌더링했습니다.

Minecraft/Cobblemon 안에서의 등록과 전투 재생은 검증하지 않았습니다. 이 파일은 새 종을 등록하는 모드 JAR나 완성된 리소스팩이 아닙니다. Cobblemon 버전에 맞는 resolver/poser, 종·진화·능력치·스폰 데이터와 연결해야 합니다. Bedrock geometry는 Java의 기본 렌더러에서 단독으로 읽히지 않으며 호환 모드가 필요합니다. 발광 마스크도 대상 렌더러에 연결해야 게임 안에서 발광합니다. 물줄기는 호환성을 위해 불투명한 픽셀 파츠입니다.

`tools` 폴더에서 `python build.py`로 `tools/pack`에 모델을 다시 생성할 수 있습니다. Python 3와 Pillow가 필요합니다. `python validate.py`로 생성본을 검증합니다. 렌더 도구에는 Blender 4.3 이상이 필요합니다. 원본 마인크래프트 캠페인 파일은 변경하지 않았습니다.
