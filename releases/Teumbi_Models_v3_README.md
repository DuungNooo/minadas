# 틈비 V3 — 생물형 실루엣과 개별 모션

V2의 로봇·갑옷 같은 인상을 줄이고, 큰 얼굴과 동공, 작은 입, 과장된 머리·몸통 비례, 적은 색면으로 다시 제작한 원본 몬스터 9종입니다. 모든 종에 노출된 단일 코어라는 가족 특징을 남겼습니다.

## 확인 방법

ZIP을 압축 해제하고 `VIEW_MODELS.html`을 Chrome·Edge 등 WebGL 브라우저에서 여세요. 인터넷 연결이 필요하지 않습니다.

- 모델별 기본 자세와 6종 모션을 선택할 수 있습니다.
- 재생/일시정지, 처음부터 재생, 시간 슬라이더로 준비 동작·타격·회복 구간을 확인하세요.
- 드래그로 회전, 휠로 확대합니다. 정면·뒤쪽 보기와 자동 회전도 제공합니다.
- `previews/role-motions.gif`는 최종형 4종의 고유 동작을 나란히 비교합니다. 개별 GIF도 포함했습니다.
- `blockbench/*.bbmodel`은 Blockbench에서 여는 편집 원본이며 PNG와 애니메이션을 내장했습니다.

## 디자인과 움직임

| 계열 | 생물형 특징 | 고유 동작 |
|---|---|---|
| 틈비 | 비대칭 알껍질, 작은 미소, 부유하는 한 개의 코어 | 기웃거리기, 껍질을 모았다 박치기, 껍질을 벌리고 코어 맥동 |
| 불꽃 | 큰 주둥이와 송곳니, 비대칭 뿔, 짧은 발, 몸에서 자란 도끼 손 | 한쪽 도끼 베기, 몸을 낮춘 뒤 도약해 양팔로 강타, 무게가 실린 발걸음 |
| 전기 | 동공 있는 큰 눈, 번개 귀·앞머리, 구름형 하체, 몸에 연결된 피뢰침 | 귀와 피뢰침의 지연된 반응, 축전 준비 후 몸을 젖혀 방출, 가벼운 이동 |
| 풀 | 큰 씨앗 얼굴, 통통한 몸통, 뿌리 발, 잎 부채 모양 양손 | 느린 호흡, 뒤뚱걷기, 웅크린 뒤 두 잎을 중앙에서 결합하고 다시 펼치기 |
| 물 | 진주색 얼굴, 지느러미 귀, 물결 꼬리, 팔에서 자란 하프 | 오른손으로 하프를 받치고 왼손으로 현을 튕기기, 순차적으로 흔들리는 물줄기 |

모든 모델에 `idle / walk / attack / special / hurt / faint` 6개 클립을 넣었습니다. 종마다 타이밍과 자세가 다르며, 준비·실행·반동·회복 구간을 분리했습니다. 눈 깜빡임과 코어 맥동에는 scale 채널을 사용하고, 전완·귀·꼬리·현 등을 독립 본으로 나눴습니다. 기절 동작은 마지막 자세를 유지합니다. 다른 동작은 기본 상태로 돌아옵니다.

## 파일

- `blockbench`: 편집 원본 `.bbmodel`, 애니메이션 포함
- `models`: Bedrock 형식 `.geo.json`
- `textures`: 128/256 픽셀 아틀라스, 코어·고열부 발광 마스크. 일반 눈은 발광하지 않음
- `animations`: 독립 `.animation.json`, 합계 54개 클립
- `glb`: 일반 뷰어용 정적 텍스처 모델. 애니메이션은 bbmodel/animation.json을 사용
- `previews`: 실제 모델 렌더, 실제 애니메이션을 캡처한 GIF, 렌더 원본 해시 기록
- `source`: 큐브·본·UV·정방향 애니메이션 데이터
- `tools`: 모델, 텍스처, 오프라인 뷰어와 미리보기 생성·검증 코드

## 검증과 적용 범위

9종의 큐브·UV·본 계층과 Blockbench/Bedrock 좌표 변환, 내장/외부 텍스처, 54개 애니메이션의 본·키프레임 참조를 자동 검사했습니다. Chromium WebGL에서 scale의 피벗 적용, 전체 모델과 6종 모션의 재생, 시간 이동·재시작·마지막 자세 유지·화면 범위를 검사했습니다. 고유 동작의 실제 프레임을 보고 방패 결합과 하프 연주 자세를 조정했습니다. 미리보기는 생성형 콘셉트 이미지가 아니라 이 파일의 실제 큐브와 텍스처입니다.

Minecraft/Cobblemon 안에서의 실행은 아직 검증하지 않았습니다. 이 ZIP은 모드 JAR나 종 등록을 포함한 완성 애드온이 아니며, 사용하는 Cobblemon/렌더러 버전에 맞춰 종·진화·스폰·resolver/poser 및 게임 동작에 연결해야 합니다. 물줄기는 호환성을 위한 불투명 픽셀 파츠입니다. 발광 마스크는 지원 렌더러에 별도로 연결해야 합니다.

모델 재생성은 `tools` 안에서 `python build.py`, 구조 검증은 `python validate.py`입니다. Python 3와 Pillow가 필요합니다. Blender 렌더 도구는 Blender 4.3+, 브라우저 검사·GIF 도구는 Node.js/Playwright/Chromium 및 Pillow가 필요합니다. 시트의 한글 폰트 경로는 OS에 맞게 조정할 수 있습니다.
