# 일반 플레이어 UX 규칙

## 절대 원칙
일반 플레이어에게 명령어 입력을 요구하지 않는다.

## 첫 접속
자동으로 입학 검사 시작
→ 선택지 클릭
→ 결과 자동 저장
→ 주 적성 연구 자동 개방
→ 다음 목표가 UI/NPC로 안내

## NPC
우클릭
→ 초상화/Avatar 대화창
→ 대화 / 의뢰 / 선물 / 관계 / 상점 / 훈련 버튼

## 퀘스트
FTB Quests에서 자동 표시
실제 게임 행동으로 자동 진행:
- 지역 도달
- 몬스터 처치
- 아이템 확보
- 제작
- 마법 실습
- 퍼즐
- NPC 대화
- 던전 완료
- 보스전

## 캐릭터 정보
아카데미 안내 NPC의 [내 정보] 버튼
→ 스탯 / 주 적성 / 보조 적성 / 추천 무기 / 현재 아카데미 등급 표시

## 메인 스토리
메인 NPC에게 퀘스트 마커/대화
→ 다음 지역/임무 안내
→ 완료 시 자동 다음 단계

## 호감도
NPC 대화창에서 [선물하기]
→ 손에 든 아이템 1개 사용
→ 호감도 상승
→ 20/40/60/80 도달 시 개인 이야기 자동 개방

## 유저에게 노출하지 않을 것
- /fantasia_exam
- /fantasia_stats
- /fantasia_content
- /fantasia_npc
- /fantasia_story
- /fantasia_bonds

이 명령들은 내부 액션용이며,
Easy NPC 버튼/FTB/NPC 이벤트가 대신 호출한다.

## OP만 사용
- 재검사
- 전체 초기화
- 스탯 보정
- 스토리 강제 진행
- 디버깅
