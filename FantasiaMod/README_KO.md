# Fantasia Campaign 1.2.0 RC2

Minecraft 1.21.1 / NeoForge 21.1.224 이상 / Java 21. 서버와 모든 클라이언트에 같은 JAR을 설치합니다.

이번 버전은 검사·재검사·NPC 대화·인연·무기 숙련·마법 연구를 Java 모드로 옮긴 실행 검증용 확장판입니다. 캠페인 데이터와 맵 생성 기능도 JAR 안에 들어 있습니다. KubeJS는 필요하지 않습니다.

## 설치와 기존 버전 업데이트

1. 게임과 서버를 완전히 종료합니다. 기존 월드를 백업합니다.
2. `mods/fantasia-campaign-1.2.0-rc.2.jar`를 사용 중인 인스턴스의 `mods`에 넣습니다.
3. 기존 설치라면 아래 충돌 파일을 **게임 폴더 밖에 백업한 뒤** 비활성화합니다. 월드 자체는 삭제하지 않습니다.

- `kubejs/server_scripts/fantasia_exam_runtime.js`
- `kubejs/server_scripts/fantasia_campaign_runtime.js`
- `kubejs/server_scripts/fantasia_magic_runtime.js`
- 이전 `fantasia_core` 보호 모드 JAR
- 플레이할 월드의 `datapacks/fantasia_campaign`과 `datapacks/fantasia_all_spells` (동명 ZIP 포함)

Python 3.11 이상이 있다면 설치 ZIP의 스크립트가 위 항목을 `fantasia-backups`로 옮기고 새 JAR을 설치합니다.

```text
python install.py --instance "마인크래프트 인스턴스 폴더 경로"
```

변경 전 목록만 보려면 `--dry-run`을 붙입니다. 스크립트는 `level.dat`, 지역 파일, 플레이어 파일을 삭제하지 않습니다. 다른 모드와 스크립트도 유지합니다.

기존 KubeJS 검사·적성·인연 기록은 플레이어 NBT에서 한 번 가져옵니다. 지역 진행은 기존 점수판을 사용합니다. 월드 변환 전 전체 백업은 보관하세요.

## 마법 모드

Iron’s 없이도 검사·NPC 대화·기본 장비 전투와 원정을 진행할 수 있습니다. 주문 연구와 시전에는 다음 조합이 필요합니다. 실제 서버 검증에 사용하는 버전입니다.

- Iron’s Spells ’n Spellbooks `1.21.1-3.16.3`
- Iron’s Lib `1.21.1-2.2.0`
- GeckoLib `4.9.3` (NeoForge 1.21.1)
- Curios `9.5.1+1.21.1`
- Player Animator `2.0.4+1.21.1-forge`

제3자 모드 바이너리는 이 배포 ZIP에 포함하지 않습니다. Python이 있으면 `python download_dependencies.py`로 해시를 검증하며 별도 `magic-dependencies` 폴더에 내려받을 수 있습니다. 받은 파일을 설치할 때는 기존 동일 모드의 JAR을 먼저 백업·분리하세요. 서버의 `config/irons_spellbooks-server.toml`에서 `spellGriefing = false`, `disableAdventureModeCasting = false`를 사용합니다(검증 조합의 기본값). `dependencies.json`에 공식 배포 URL과 해시가 있습니다. 이전 버전의 동일 모드 JAR과 동시에 설치하지 마세요. FTB Quests는 선택 사항이며 새 진행 기록은 모드 화면에서 확인합니다.

## 처음 시작

새 월드나 기존 캠페인 월드를 열면 `fantasia:campaign` 차원에 맵이 생성됩니다. 최초 생성 중에는 기다려 주세요. 생성 도중 서버가 종료된 경우 완료되지 않은 생성 작업을 재시작합니다. 생성 완료된 맵은 그대로 사용합니다.

- 첫 접속 시 입학 검사 12문항을 전용 화면에서 진행합니다.
- `J` 키: 현재 목표·검사 결과·재검사·원정 기록·무기 숙련.
- NPC 우클릭: 대화와 원정, 훈련, 치료, 연구, 인연 이야기.
- 캠페인 NPC는 거래창을 열지 않습니다. 일반 주민 거래는 유지합니다.
- 기초 장비는 카일에게 받습니다. 갑옷과 방패는 직접 장착하세요.
- 표적·마법부여·양조·실전의 기초 과정을 마치고 아델린의 첫 원정을 완료하면 네 지역으로 나갈 수 있습니다.
- 원정에서 공중에 표시된 목표를 우클릭합니다. 완료한 목표는 사망·이탈 후에도 유지됩니다. 진행 중 전투와 호위는 실패 시 다시 시작합니다.
- 원정 중 귀환: `J` → `원정 중단 · 아카데미로`.

새 캠페인 월드 사용을 권장합니다. 캠페인은 전역 게임 규칙을 변경합니다(인벤토리 유지, 자연 몹 생성 중지, 몹의 지형 파괴 중지, 불 번짐 중지, 보통 난이도). 캠페인 참가 플레이어는 모험 모드로 전환됩니다.

## 현재 들어 있는 콘텐츠

- 기본 지역 11곳과 별도 원정 맵 12곳.
- 정전 사건, 네 지역 심층 조사, 수도 피난, 지하 연구소, 교단 은신처와 교수 구출, 세 전선, 마왕성의 과거 기록.
- 원정당 조사·전투·공명 장치·호위·지휘관·증거 확보, 총 72개 목표.
- 7명 동료의 인연 이야기 총 28장면. 선물 반복 없이 이야기 완료로 인연을 쌓을 수 있습니다. 선택은 저장됩니다.
- 9계통, 27단계 연구. 실제 시전·명중·회복·이동·소환 기록을 사용합니다. 111개 주문 ID에 연구 조건을 연결했습니다. 현재 Iron’s에 존재하는 주문만 각인 목록에 표시합니다.
- 11개 무기군의 숙련 기록. 추천 무기는 숙련이 2배로 오릅니다. 근접 무기 숙련은 공격력 보너스를 주며 원거리·마법 숙련은 현재 성장 기록입니다.
- 지역 조사 → 방어전 → 봉인의 진실 → 세 전선 → 마왕성 결전 → 4개 결말.
- 진실 결말은 연구소·교수 구출·왕좌 기록과 2명 이상의 깊은 인연이 필요합니다.

## 재검사와 복구

일반 플레이어는 `J` → 검사 결과 → 재검사를 사용할 수 있습니다. 관리자 권한 없이 본인의 검사만 다시 시작합니다.

관리자와 서버 콘솔:

```text
/fantasia_admin restart 플레이어닉네임
/fantasia restart 플레이어닉네임
```

대상은 온라인이어야 합니다. 게임에서는 OP 2 이상이 필요합니다. 콘솔에서는 `/` 없이 입력합니다. 재검사는 검사 점수와 검사 단계만 초기화하고 지역 진행·연구·원정·인연은 유지합니다.

## 플레이타임과 범위

개발 목표는 약 30시간입니다. **30시간 실제 플레이로 검증한 완성본은 아직 아닙니다.** 현재 콘텐츠의 실제 첫 플레이 시간은 측정되지 않았습니다. 목표 수나 연구 횟수를 플레이 시간으로 환산하지 않습니다. `J` 화면의 캠페인 접속 시간·활동 추정 시간을 통해 실측을 남깁니다. 시간 기록은 진행 제한에 사용하지 않습니다.

원래 문서의 장기 기획 전체가 구현된 것은 아닙니다. 커스텀 보스 모델·전용 애니메이션, Cataclysm 보스 연동, 전설 무기 제작과 별도 융합 주문은 아직 포함하지 않습니다. 현재 지휘관과 보스는 바닐라 엔티티에 체력·기믹·경고 효과를 더한 구성입니다. 원정 맵은 생성된 연결형 방 구조이며 모든 지역이 수작업 미술 맵인 것은 아닙니다.

클라이언트 화면을 직접 조작하는 전체 플레이와 장기 밸런스 검증은 남아 있습니다. 검증 결과는 `VALIDATION_MOD_KO.md`를 확인하세요.

## 빌드

Java 21 JDK 설치 후:

```text
cd FantasiaMod
./gradlew build
```

소스에서 데이터도 다시 생성하려면 저장소 루트에서 `python tools/build_map.py`, `python tools/build_campaign.py`, `python tools/build_mod_resources.py` 순서로 실행합니다(Node.js 필요). 실제 서버 테스트는 `./gradlew runGameTestServer`입니다. 이 통합 테스트에는 위의 Iron’s 모드 조합을 개발 인스턴스 `run-verification/mods`에 설치해야 합니다. 테스트용 월드 프리셋과 검증 클래스는 배포 JAR에서 제외합니다.
