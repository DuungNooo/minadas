# 1.2.0 RC1 검증 기록

기준: Minecraft 1.21.1, NeoForge 21.1.224, Java 21. 검증 일자: 2026-10-25 (한국 시간).

## 실제 서버에서 통과

NeoForge GameTest 서버와 실제 ServerPlayer/발전과제 API로 13개 통합 검사를 실행했습니다. 네트워크 수신 클라이언트는 테스트용 연결로 대체했으며 실제 GUI 조작 검사는 아닙니다.

1. 12문항 검사 완료와 재검사, 연구·원정·인연 보존.
2. 이전 문항·범위 밖 답변의 중복 점수 방지.
3. NPC 일반 우클릭·정밀 우클릭의 거래 취소, 일반 주민 거래 유지.
4. 관리자 재검사 명령 실행·권한 거부·본인 재검사 확인 화면.
5. 위조·재사용 메뉴 토큰 거부.
6. 실제 원정 상호작용 엔티티에서 목표 기록을 한 번만 진행.
7. 기초 과정 네 종류의 발전과제 조건.
8. 기본 11개 지역과 원정 12개 맵 생성 완료, 도착 위치 바닥·머리 공간.
9. 기존 KubeJS 플레이어 NBT의 1회 이전.
10. 한국어 화면 데이터와 선택 패킷 직렬화.
11. 실제 Iron’s SpellPreCastEvent의 연구 제한·기본 주문 허용·지형 파괴 주문 차단, 시전 기록.
12. 실제 Iron’s 마법서 발급·화면 선택 경로·아이템 컴포넌트 주문 각인.
13. 사망 복제 시 독립적인 진행 데이터 복사, 위조 메뉴 진행 방지.

`All 13 required tests passed`, Gradle 종료 코드 0을 확인했습니다. 고정 tick 지연 대신 실제 청크 활성 상태를 기다리는 검사로 수정해 검증했습니다.

별도 일반 NeoForge 서버에는 배포 JAR과 아래 마법 모드 조합만 설치했습니다. 개발용 테스트 클래스·월드 프리셋을 제외한 JAR로 정상 부팅, `fantasia:campaign` 차원 사용, `#ready = 1`, `#exp_ready = 1`, 정상 저장 종료를 확인했습니다.

- Iron’s `1.21.1-3.16.3`, Iron’s Lib `1.21.1-2.2.0`
- GeckoLib `4.9.3`, Curios `9.5.1+1.21.1`, Player Animator `2.0.4+1.21.1-forge`

테스트 환경의 Mojang 인증 키 조회와 Iron’s Lib 외부 데이터 조회에는 네트워크 오류가 남았습니다. 게임 로딩·발전과제·위 검사·맵 생성·서버 저장 종료는 진행됐습니다. 클라이언트 리소스 다운로드가 제한돼 전용 화면을 직접 클릭하는 시각 검사는 수행하지 못했습니다.

## 정적 검사와 설치 검사

- Minecraft 1.21.1 명령 트리로 342개 함수의 6,473개 명령 파싱.
- 바닐라 블록·상태·엔티티, fill 상한, 함수·발전과제 참조 검사.
- 12개 원정의 72개 목표·연결 통로·도착 공간 검사.
- 배포 함수에 채팅 `/trigger` 선택지가 없는지 검사.
- 설치 스크립트 5개 검사: 충돌 파일 백업, 월드·무관 파일 보존, dry-run, 복사 실패 롤백, 외부 경로 링크 거부, 같은 경로 JAR 재설치. 첫 항목에 여러 검증을 포함합니다.
- ZIP CRC 및 파일별 SHA256, JAR의 개발용 검증 클래스·테스트 월드 프리셋 제외 검사.

## 남아 있는 검증과 범위

- 사람이 처음부터 엔딩까지 플레이하는 전체 검증.
- 실시간 화면 배치·키 조작·멀티플레이 동시 진행의 체감 검증.
- 실제 플레이타임과 난이도 밸런스. **약 30시간은 목표이며 달성 실측은 없습니다.**
- 원래 장기 기획의 커스텀 모델·애니메이션·Cataclysm 보스·융합 주문·전설 제작은 이번 구현 범위에 포함하지 않았습니다.

성공한 자동 검사를 ‘모든 게임 상황에서 오류 없음’으로 해석하지 않습니다.
