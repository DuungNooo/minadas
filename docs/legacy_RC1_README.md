# Fantasia: 균열의 왕 — 1.1.0 RC1

Minecraft **1.21.1 / NeoForge**용 캠페인 수정본입니다. 첨부된 1.0.1의 검사·연구 데이터를 바탕으로, 실제 맵 생성과 시작부터 엔딩까지의 진행을 추가했습니다.

**이 버전은 실게임 검증 전 RC입니다.** 함수 구문, 데이터 참조, 진행 로직, KubeJS 회귀 검사는 통과했지만 이 작업 환경의 다운로드 정책 때문에 Minecraft/NeoForge 서버를 구동하지 못했습니다. 50~70시간 플레이타임이나 모든 모드 조합의 무오류를 검증한 버전은 아닙니다. 원본의 장기 기획 문서와 이번에 구현한 내용은 구분해야 합니다.

## 플레이에 필요한 구성

| 구성 | 용도와 기준 |
|---|---|
| Minecraft Java 1.21.1, Java 21, NeoForge 21.1.x | 원본의 NeoForge 기준 버전은 21.1.224 |
| KubeJS 2101.7.2 계열 + 해당 버전의 Rhino | 필수: 12문항 검사, 스탯, 인연, 연구 UI. 검토한 Rhino 소스 의존성은 2101.2.7-build.81 |
| Iron's Spells 'n Spellbooks 1.21.1 | 마법 플레이에 필요. API 검토 기준은 1.21.1-3.16.3이며, GeckoLib / playerAnimator / Curios / Iron's Lib 등 해당 배포판의 필수 의존성을 함께 설치 |
| FTB Quests 2101 + FTB Library / FTB Teams 및 해당 버전 의존성 | 선택: 12개 챕터, 70개 퀘스트로 진행 표시. 소스 검토 기준 2101.1.37 |

모드 JAR는 이 ZIP에 포함하지 않았습니다. 설치된 모드의 게임 버전과 로더를 모두 맞춰야 합니다. Easy NPC와 Cataclysm은 이번 캠페인의 필수 의존성이 아닙니다. NPC는 맵과 함께 생성되며, 전투는 바닐라 엔티티에 체력·장비·단계 규칙을 적용합니다.

**기존 `fantasia_core-0.2.0.jar` 등 이전 FantasiaCore JAR는 제거하세요.** 기존 JAR의 중복 명령과 메모리 기반 진행이 KubeJS와 충돌할 수 있습니다. 이번 기본 구성은 KubeJS 네이티브 이벤트로 주문 잠금과 폭발 블록 보호를 처리하므로 추가 Core JAR 빌드가 필요 없습니다. 별도 제공되는 Java 소스는 대안이며 컴파일 검증은 하지 못했습니다.

## 싱글플레이 설치

게임을 종료하고, 현재 1.21.1 NeoForge 프로필을 복제한 뒤 적용하는 방법을 권장합니다. FTB 퀘스트 설정은 프로필 전체에 적용됩니다.

1. ZIP의 `kubejs/server_scripts` 안 `fantasia_*.js` 3개를 게임 프로필의 같은 위치에 넣습니다. 기존 동명 파일은 백업하고 교체합니다.
2. `config/ftbquests/quests`는 기존 폴더를 백업한 뒤 폴더째 교체합니다. FTB Quests가 없어도 메인 진행은 동작하도록 작성했습니다.
3. ZIP의 `world` 폴더를 **통째로** 게임 프로필의 `saves`에 복사하고 이름을 `Fantasia_Campaign_RC1`로 바꿉니다. Minecraft에서 `Fantasia - 균열의 왕 1.1.0` 월드를 엽니다.

`world/level.dat`는 새 월드 템플릿입니다. 지형을 미리 저장한 `.mca` 월드가 아니라, **첫 실행 때 맵을 자동 건설**하는 구조입니다. 첫 로딩 때 잠시 기다리면 아카데미로 이동합니다. 생성 완료 전에는 종료하지 않는 것이 좋습니다. 생성 작업은 청크 로딩을 기다리고 나누어 실행되며, 완료 후에는 재접속해도 맵을 다시 지우지 않습니다.

기존 생존 월드에 `level.dat`를 덮어쓰지 마세요. 기존 월드에 수동 적용하려면 데이터팩 폴더만 복사하고 서버를 완전히 재시작해야 하며, 이 팩은 접속자를 캠페인으로 보내고 모험 모드 및 keepInventory/mobGriefing/doFireTick/doMobSpawning 규칙을 적용합니다. 그래서 새 캠페인 월드 사용을 기본으로 합니다.

Python 3.10 이상이 있으면 선택적으로 백업 설치 도구를 사용할 수 있습니다.

```sh
python install.py --instance "게임 프로필 경로" --dry-run
python install.py --instance "게임 프로필 경로"
```

기존 월드가 같은 이름으로 있으면 덮어쓰지 않고 중단합니다. 기존 동명 스크립트·퀘스트와 이전 FantasiaCore JAR는 `fantasia_backups/시간/`에 보관합니다. 사용자에게 필요한 모드 자체를 다운로드하는 도구는 아닙니다.

## 서버 설치

서버를 종료한 뒤 `kubejs`와 `config/ftbquests/quests`를 위와 같이 설치합니다. `world` 템플릿은 서버 루트에 `Fantasia_Campaign_RC1`라는 새 이름으로 복사하고 `server.properties`의 `level-name=Fantasia_Campaign_RC1`로 설정합니다. `enable-command-block` 설정이나 일반 플레이어 OP 권한은 필요 없습니다. Java 21로 NeoForge 서버를 완전히 재시작합니다.

```sh
python install.py --instance "서버 경로" --mode server
```

설치 도구는 서버의 `level-name` 설정을 자동 변경하지 않습니다. 서버와 클라이언트의 Iron's/필수 라이브러리 버전은 맞춰 주세요.

## 구현한 플레이 흐름

입학 검사 12문항 → 카일에게 장비 수령 및 기초 전투 → 아델린을 통해 네 지역 자유 순서 탐사 → 수도의 3회 방어전 → 봉인서고 조사 → 북부·동부·남부 전선 → 마왕성 결전 → 4개 결말 중 하나 선택.

- 아카데미, 불타는 광산, 얼어붙은 수로, 침식된 숲, 낙뢰 평원, 봉인서고, 수도, 세 전선, 마왕성의 **11개 구역**을 생성합니다.
- NPC 14명과 조사·퍼즐 장치 16개가 자동 배치됩니다. NPC 및 공중 이름표 아래 장치를 우클릭하고 채팅 버튼을 눌러 조작합니다.
- 광산 구출, 수로 작동 순서, 숲 정화 순서, 평원 제한 시간 장치, 서고 기록 조사, 실제 몬스터 전투가 진행 조건입니다.
- 벨카리온은 첫 육체 전투 → 두 봉인석 안정화 → 최종 육체와 호위병 전투의 세 단계입니다. 전용 보스 모델이나 별도 애니메이션 자산은 포함하지 않았습니다.
- 전투는 근처의 조건을 만족하는 플레이어들을 함께 참가시킵니다. 사망·귀환·이탈한 플레이어는 해당 도전 보상을 받지 않습니다. 모두 이탈하면 다시 시작할 수 있습니다. 완료한 지역 기록은 개인별로 유지됩니다.
- 노아에게 연구용 마법서를 받고 **주 손에 든 철 마법서**에 해금된 주문을 각인합니다. 9계통·27개 연구와 원본 111개 주문 잠금을 연결했습니다. 직접 지형을 부수는 2개 주문은 맵 보호로 사용 제한됩니다. 기본 각인은 1레벨, 책당 6슬롯입니다.
- 세라핀에게 치료·식량·화살을 받을 수 있습니다. 카일에게 선택 실습 재료를 받아 표적·마법부여·양조를 연습할 수 있습니다. 선물은 주 손 아이템을 실제로 1개 소비하며 거리와 30초 대기 시간을 검사합니다.
- FTB 퀘스트는 수동 체크박스가 아니라 실제 달성 기록으로 완료됩니다. 연구에 필요한 모든 단계가 캠페인 진행에서 열리므로 별도 모드 보스 출현에 의존하지 않습니다.

`map_preview.png`와 `map_preview.svg`는 실제 생성 명령의 블록 배치를 그린 평면도입니다. Minecraft 게임 화면 캡처는 아닙니다.

## 검증 및 남은 확인

`VALIDATION_KO.md`에 수행한 검사와 미실행 항목을 구분했습니다. 설치 후 실제 클라이언트에서는 첫 입장, 입학 검사 버튼, NPC 우클릭, 주문 각인/시전, 사망 후 복구, FTB 진행 반영, 친구와 동시 전투를 확인해야 합니다. 로그 확인 위치는 `logs/latest.log`와 `logs/kubejs/server.log`입니다.

원본 문서의 50~70시간 운영, 개별 주문별 장기 의뢰 111개, 무기별 숙련 트리, 전용 보스 모델, 엔드게임 레이드 전체는 이번 구현 범위가 아닙니다. 이번 수정본은 실제 맵과 하나의 완주 가능한 캠페인 흐름을 구현한 RC입니다.
