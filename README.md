# Fantasia Campaign

Minecraft 1.21.1 / NeoForge용 캠페인 모드입니다. 최신 구현은 **1.2.0 RC1**입니다.

[설치·플레이 안내](FantasiaMod/README_KO.md) · [실제 검증 결과](FantasiaMod/VALIDATION_MOD_KO.md)

- 전용 화면에서 12문항 검사·본인 재검사·NPC 대화.
- 캠페인 NPC의 거래창 차단. 기존 관리자 재검사 명령 복구.
- 기본 11개 지역, 원정 12개와 72개 목표, 7명의 인연 이야기 28장면.
- 마법 연구·주문 각인·실습 기록·무기 숙련·4개 결말.
- 실제 NeoForge 서버 통합 검사 13개와 설치 검사 5개 통과.

**플레이타임 약 30시간은 개발 목표이며, 실제 30시간 플레이 검증을 완료한 버전은 아닙니다.** 원래 문서의 장기 기획 전체가 구현된 것도 아닙니다. 현재 범위와 남은 작업은 설치 안내에서 확인하세요.

배포 JAR과 설치 ZIP은 `releases`에 있습니다. 과거 1.1.0 KubeJS 배포본은 보관용입니다. 새 모드와 이전 Fantasia 스크립트·데이터팩을 함께 활성화하지 마세요.
